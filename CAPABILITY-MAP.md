# Capability map

This is the honest high level picture of the project. It is not a scorecard and it does not show every experiment. It shows where evidence is strongest and where the work is still thin.

| Area | Current position |
|---|---|
| Internal computation | Passed the project tests |
| Stored program execution | Passed the project tests |
| Closed loop operation | Passed within the tested range |
| Memory and addressing | Stronger evidence base, with open capacity limits |
| Choosing a subgoal and first action | Passed the project tests |
| Rule learning | Passed on the tested tasks |
| Language to machine translation | Passed on the tested program classes |
| Language, execution and computed-result readout | Connected on one held out problem set at 7.2B |
| Program correction from execution feedback | Tested approaches did not pass |
| Work split between model and trained support | Candidate evidence says both are needed |
| Performance and measurement | Actively measured, with scale still limited |
| World to system input | Narrow observation and prediction tests passed; broad transfer open |
| Perception of a real environment | Broad real world perception not shown |
| System to world action | Passed fixed controlled tests |
| Narrow end to end chain | Passed a repeated simulated-environment loop and a separate language-to-result chain |
| Open ended task performance | Not shown |

## How to read this

The project has more evidence for the internal machine than for its connection to the outside world. As of 5 September 2026, both a repeated environment loop and a language-to-result chain have passed narrow tests. They are separate results, not one combined general system. Broader input, dependable open ended output and program correction remain open.

The strongest next use of additional support is therefore not another isolated internal capability. It is the work needed to connect the tested pieces to a real task, test them together and find out whether they hold up.

The map deliberately separates accepted results from early work and open gaps. See [RESULTS.md](RESULTS.md) for the result summaries and [LIMITATIONS.md](LIMITATIONS.md) for the limits that apply to all of them.
